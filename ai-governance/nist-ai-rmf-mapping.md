# NIST AI Risk Management Framework (AI RMF 1.0)

## Purpose
Align AI governance activities with NIST AI RMF’s four core functions.

---

## Function 1: GOVERN

| Sub-category | Description | Our Implementation |
|--------------|-------------|---------------------|
| GV.AI-1 | Legal & regulatory requirements mapped | Obligations Register (AI Act, ISO 42001) |
| GV.AI-2 | AI risk management integrated with enterprise risk | AI risk register, RCSA workbook |
| GV.AI-5 | Transparency & documentation | AI system inventory, model cards |

## Function 2: MAP

| Sub-category | Description | Our Implementation |
|--------------|-------------|---------------------|
| MP.AI-1 | AI system context and intended use | Use case catalog (see `ai-governance/ai-use-cases.md`) |
| MP.AI-2 | Data sources & dependencies | Data lineage records |
| MP.AI-4 | Potential benefits and harms | AI impact assessment |

## Function 3: MEASURE

| Sub-category | Description | Our Implementation |
|--------------|-------------|---------------------|
| MS.AI-1 | AI risk assessment methods | STRIDE threat model extended for AI |
| MS.AI-3 | Robustness & security testing | Prompt injection lab, adversarial testing |
| MS.AI-5 | Performance monitoring | KRI dashboard (model drift, accuracy) |

## Function 4: MANAGE

| Sub-category | Description | Our Implementation |
|--------------|-------------|---------------------|
| MG.AI-1 | Risk treatment & prioritization | Risk register with exploitability scoring |
| MG.AI-2 | Incident response for AI systems | AI incident response playbook |
| MG.AI-3 | Monitoring & continuous improvement | Monthly AI controls review |
